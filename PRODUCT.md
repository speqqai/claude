# Speqq Product Context

## What Speqq Is

- Speqq is a product for spec-driven software development.
- Speqq is a web application accessed from the browser.
- Our users do software development with AI agents: software engineers, product managers, designers, and anyone else building software this way.
- The product is optimized for users developing specs and building them with AI coding agents.

## Our Goal

- Make spec-driven software development the most efficient way to build software.
- Everything we do makes software development more efficient — for our users and for the broader industry. That is all we care about.
- Our long-term push is toward fully autonomous software development driven by specs.

## Our Team

- We are a small team. Only two human engineers work on this product.

## Why Code Quality Is Survival

This is a business constraint, not a preference. Read it as a hard rule.

- Two engineers maintain this entire product. Every line of code is a line we must own, debug, and maintain forever.
- Inefficient or buggy code is an existential threat. If we ship software that is not efficient and not bug-free, maintenance cost grows faster than two people can absorb, and we cannot reach our goals or build software profitably.
- Build reusable primitives, never hyper-specific one-offs. A one-off solves today's task and adds permanent maintenance that no one else benefits from. A primitive is built once and reused everywhere.
- Codebase efficiency is how we survive. Favor the smallest, clearest, most reusable implementation that fully solves the problem — never more.
